# DentaLog

Personal work log for Dra. Sofía — daily Gesden agendas, payments, insurance,
patient history and the monthly clinic liquidación check.

- **App:** `index.html` (single file, works offline once opened; installable on iPhone via *Share → Add to Home Screen*).
- **No patient data is stored in this repository.** Data lives on each device and syncs
  **AES‑256 encrypted** (passphrase never leaves the device) to the private repo `dentalog-data`.
- PDF reading uses pdf.js in the browser; nothing is uploaded anywhere.
